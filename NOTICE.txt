- rM2-stuff by Timothy Werquin (timower), GPL-3.0.
  https://github.com/timower/rM2-stuff
  Source of the vendored emulator core (apps/tilem/emu/, copied unchanged
  from the tree at commit 9126d7ff3093e5598342a7236f305e6331d9ed79, as
  checked out from the github.com/Eeems/rM2-stuff fork) and of the
  11-row keypad table (labels and scancode order) in src/bin/tilem/keymap.rs,
  translated from apps/tilem/main.cpp into Rust. No other rM2-stuff code is
  used; the display, input and rendering code here is new.

- QTFB: the display/input HAL (src/bin/tilem/rmpp_hal/) is our own code
  (shared with our chessMarkable RPP port) and speaks the QTFB shared-memory
  protocol of rm-appload (https://github.com/asivery/rm-appload). Protocol
  documentation credit: https://github.com/AnotherStranger/qtfb-client.
